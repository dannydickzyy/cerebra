The modeling process followed a controlled experimental approach: 1. Define the prediction target and input features. 2. Separate the dataset into training and testing sets. 3. Evaluation Metrics Because the target variable is highly imbalanced, several metrics were used. 5.1 Accuracy Accuracy measures the proportion of all predictions that were correct. However, accuracy can be misleading in this dataset because approximately 95% of observations belong to class 0 . For example, a model that predicts every case as class 0 can achieve approximately 95% accuracy while detecting none of the positive cases . 5.2 Precision Precision measures how many predicted positive cases were actually positive. A low precision means that many cases identified as positive were false positives. 5.3 Recall — Primary Metric Recall was treated as the primary evaluation metric . Recall=TPTP+FNRecall = \frac{TP}{TP+FN} 

PAGE 28
Recall answers: Among all actual positive cases, how many did the model successfully identify? This is particularly important for a screening/risk-identification context because false negatives represent positive cases that the model failed to identify. 5.4 F1-score F1-score provides a balance between precision and recall. It was included because maximizing recall alone could result in a model that labels a very large number of negative cases as positive. 5.5 ROC-AUC ROC-AUC was used to evaluate the model's ability to distinguish between the two classes across different classification thresholds. A value around 0.50 indicates little discrimination between the classes. 5.6 PR-AUC Precision-Recall AUC was also introduced because the positive class represents only approximately 4.85% of the data. PR-AUC is particularly informative when the positive class is relatively rare. 6. Important SMOTE Limitation There is an important methodological limitation to record. The current SMOTE experiments were performed on the already one-hot encoded feature matrix : X_train_processed This means SMOTE can generate synthetic values across encoded categorical features. For example, a synthetic observation could theoretically contain fractional values in one-hot encoded columns. Therefore, the current SMOTE experiments should be regarded as exploratory experiments , not necessarily the final preferred imbalance-handling implementation. A more appropriate categorical-aware approach would be to investigate SMOTENC or another imbalance-handling strategy that accounts for categorical variables before one-hot encoding. This is worth documenting in the methodology rather than hiding it. 18.
